# ThinkCamp GitHub Pages

Static homepage for the `thinkcamp` GitHub account.

## Publish

Create a GitHub repository named:

```bash
thinkcamp.github.io
```

Then push this folder to the repository's `main` branch. GitHub Pages will publish it at:

```text
https://thinkcamp.github.io
```

## Files

- `index.html`: page structure
- `styles.css`: responsive layout and visual design
- `script.js`: animated hero canvas
- `.nojekyll`: tells GitHub Pages to serve files as plain static assets
